# 日本国内 CV・画像認識キャリア調査（新卒の実力 × 等級 × 年収）

調査日: 2026-10-28 ／ 対象: 2027〜2028卒の学部・修士・博士（CV / 画像認識 / 3D / 自動運転の認識系）

> **信頼度の表記**
> - ◎ 公式の募集要項・報道で確認できた数値
> - ○ 就活メディアなど二次情報（時期が古い／職種が曖昧なものを含む）
> - △ 公開情報がなく、各社の新卒等級制度などから見積もった**推定値**
>
> 年収は「月給×12 + 賞与」の初年度目安（残業代・住宅手当は除く。外資は RSU 込みの TC）。△は特に幅が大きいので、最終的には各社の募集要項とオファー面談で確認すること。
>
> **掲載範囲は新卒採用のみ。** 中途採用の求人、全社員の平均年収、経験者を含む等級別の統計は載せていない。

---

## 1. 結論（先に要点）

1. **新卒の年収は「会社の格」より「入社時に付く等級」で決まる。** メガベンチャー・外資・ジョブ型に移行した大手（ソニー、富士通、NEC など）は、同じ新卒でも実力次第で入社等級が変わる。一律初任給の会社では実力差は年収にほとんど出ない。
2. **相場の分かれ目は次の3段階。**
   - 修士で研究室 + インターンをちゃんとやる → **年収 550〜700万** に落ち着く（メガベンチャー／大手研究所の通常オファー）
   - **国際学会の発表（第一著者）・OSS への有意な貢献・Kaggle Master 級**が認められる → **800万〜** が見え始める
   - **トップ会議（CVPR / ICCV / ECCV / NeurIPS）の第一著者 + 博士**、あるいは外資の Research/SWE 職 → **1,000万〜1,800万**
3. **「修士ならとりあえず上がる」わけではない。** 実績のない修士はメーカーの修士初任給（月31〜36万円）になるだけで、学部卒で SWE としてメガベンチャーに入った同期との差はほぼない。修士の2年で論文・OSS・長期インターンのどれかを作れるかどうかが分かれ目になる。
4. **大手メーカーの修士採用は「安定と長期のキャリア」と引き換えのコース。** 初年度は低めだが、終身雇用に近い形で研究開発を続けやすい。経験者を求めるメガベンチャーとは評価軸が違う。

## 3. 進路の全体像

```
                  ┌─ 研究職（リサーチャー）……PFN / Sony AI / NTT研 / CA AI Lab / 外資 Research
                  │    主な評価: 論文（トップ会議）。博士がほぼ前提で、修士はトップ会議の実績が必須
CV・画像認識 ─────┼─ MLエンジニア / 応用研究……Woven / TIER IV / Turing / メーカーの研究所
を学んだ学生      │    主な評価: 論文 + 実装力 + 実機・実データの経験
                  ├─ プロダクト ML / SWE……LINEヤフー / メルカリ / Sansan / 楽天 / 外資 SWE
                  │    主な評価: 実装力・システム設計・OSS。学部卒でも十分に戦える
                  └─ 組み込み・カメラ・医療画像……キヤノン / 富士フイルム / デンソー / パナソニック
                       主な評価: ドメイン知識・長期の研究開発。修士の一律初任給が中心
```

**判断の目安**

- **博士に進むか**: 研究職の上位等級を狙うなら、トップ会議を通せる見込みがあるかで決める。見込みがなければ修士で就職するほうが期待値は高い。
- **修士か学部就職か**: 修士の2年でできることが「研究室の課題だけ」なら、学部卒で SWE としてメガベンチャーに入り、実務2年を積んだほうが年収・市場価値の両面で上回ることが多い。
- **大手メーカー**: 終身雇用で長く研究開発をしたいなら修士が有利。初年度の年収よりも、長期の安定と研究テーマの継続性を取るコース。

## 6. 年収を引き上げるために学生のうちにやること（優先順）

1. **国際学会の第一著者論文を1本**（WACV / BMVC / ICIP / ACCV でもよい）→ Lv2 への最短ルート。トップ会議なら Lv3。
2. **有給の長期インターン**（PFN、Woven、TIER IV、Turing、メルカリなど）→ インターン中の評価がそのまま入社時の等級になることが多い。
3. **OSS 貢献**（Autoware、MMDetection、timm、Detectron2 などへのマージ済み PR）→ 実装力を客観的に証明できる。
4. **Kaggle**（CV コンペでメダル、Master 以上）→ メガベンチャーで評価されやすい。
5. **オファーは並べて交渉する**: ジョブ型・年俸制の会社では、他社のオファーを根拠にした等級の交渉が通ることがある。

## 7. 注意事項

- 本調査は新卒採用の公開情報（募集要項・報道など）と推定にもとづく。外資の新卒報酬はほとんど公開されていないため、外資の表はすべて推定値。△ の数値は根拠の弱い推定なので、意思決定には使わず各社に直接確認すること。
- 「年収」の定義（賞与・残業代・手当・RSU を含むか）は会社ごとに違う。
- 社内の当事者が肌感覚として話している「修士で適切に動けば 550〜700万前後に集中」「国際学会・OSS が認められると 800万〜」という見立ては、本調査の Lv1・Lv2 の帯と一致している。
